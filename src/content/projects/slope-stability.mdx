# AI-Driven Slope Stability Analysis

This project explores the integration of Machine Learning (ML) surrogate models with Finite Element Analysis (FEA) to evaluate the Factor of Safety (FoS) in soil slopes.

## Key Features
- **Fast Evaluation:** Reduces computation time by 90% compared to traditional numerical methods.
- **Python Integration:** Automated data extraction from PLAXIS 3D.
